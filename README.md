# Aaron Playground

Aaron Playground is a mobile-friendly kids learning website with interactive games for math, science, memory, and pattern practice.

## Features

- Math Quest: quick arithmetic questions
- Science Lab: kid-friendly science quiz questions
- Memory Match: emoji card matching game
- Pattern Pop: visual and number pattern challenges
- Responsive layout for phones, tablets, and desktops

## Tech stack

- React
- TypeScript
- Vite

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
